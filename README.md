# 돈돈 돼지 저금통 (용돈 관리 말판놀이)

주사위를 굴려 말판을 돌며 용돈을 벌고, 쓰고, 모으고, 나누는 초등 경제·금융교육 놀이입니다.
김천 경제캠프 말판놀이를 웹으로 옮겼습니다.

- 1~4명(모둠)이 한 화면에서 번갈아 합니다.
- 간식·선물은 살지 참을지 고르고, 꼭 필요한 물건은 지갑이 모자라면 저금통에서 꺼냅니다.
- 용돈기입장이 저절로 채워지고, '남은 돈 직접 계산하기'를 켜면 학생이 남은 돈을 계산해 적습니다.
- 이름과 기록은 어디에도 저장하지 않습니다.

파일 하나(`index.html`)로 된 정적 페이지이며 GitHub Pages로 배포합니다.
